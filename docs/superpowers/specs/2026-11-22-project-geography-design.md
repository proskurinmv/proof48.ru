# Блок «География проектов»

## Цель

Добавить на главную страницу Proof адаптивный блок по макету: заголовок, карта проектов и связанная карточка выбранного объекта. При наличии ключа JavaScript API Яндекс.Карт клик по точке переключает карточку. До добавления ключа отображается карта Конструктора и доступный переключатель объектов.

## Структура

- `main/index.html` — секция `.project-geography` после галереи объектов.
- `main/project-geography.css` — только стили блока.
- `main/project-geography.js` — данные объектов, переключение карточки, загрузка карты и резервный режим.
- Используются существующие изображения галереи и символы `#ui-map-pin`, `#icon_arrow_right_3` из `custom/svg_icons.html`.
- `custom/ui.css`, `custom/color.css` и `custom/buttons.css` не изменяются.

## Данные объектов

Начальный набор состоит из трёх уже представленных на странице объектов:

1. Москва — дата-центр, гидроизоляция кровли объекта критической инфраструктуры.
2. Липецк — производственный объект, ремонт и гидроизоляция.
3. Тула — складской комплекс, восстановление кровли после многократных ремонтов.

Карточка использует только подтверждённые текущей страницей сведения: город, тип объекта, название решения, краткое описание и существующее изображение. Неподтверждённые площадь и год не придумываются.

## Подключение карты

Секция получает атрибут `data-yandex-api-key=""`. Ключ вставляется только в этот атрибут.

- Пустой ключ или значение `YOUR_API_KEY`: скрипт показывает предоставленную карту Конструктора `constructor:550e1b4888ff585ce473f480f7a73f03cd8f793a50bb00bab63be2ee69dca04d` внутри iframe. Карточка переключается кнопками городов.
- Настоящий ключ: скрипт загружает JavaScript API 2.1, создаёт карту и три связанные точки. Клик по точке или кнопке города вызывает одну функцию `selectProject(projectId)`.
- Ошибка загрузки API: блок автоматически возвращается к карте Конструктора, а переключатель и карточка продолжают работать.

Ключ должен быть ограничен доменами проекта в кабинете Яндекс.Карт.

## Взаимодействие

- Первый объект выбран при загрузке.
- Активная кнопка получает `aria-pressed="true"`.
- Карточка обновляет изображение, город, тип, название и описание.
- Карточка имеет `aria-live="polite"` для сообщения об изменении экранным дикторам.
- Смена содержимого использует короткий переход прозрачности; при `prefers-reduced-motion` переход отключается.
- Точки карты и кнопки используют общий идентификатор проекта, поэтому состояние не расходится.

## Адаптивность

- Desktop: карта занимает левую широкую колонку, карточка — правую.
- Tablet: пропорции колонок уменьшаются, карточка сохраняет читаемую минимальную ширину.
- Mobile: карта, кнопки городов и карточка располагаются вертикально; высота карты уменьшается без горизонтального переполнения.

## Проверка

- Контрактные тесты разметки, трёх объектов и отдельных CSS/JS.
- Тесты переключения карточки и резервного режима без ключа.
- Проверка с тестовым значением ключа через заглушку `ymaps` без сетевого запроса.
- Визуальная проверка 1440, 1280, 1024, 768, 576, 375 и 320 px.
- Проверка клика по точке, кнопок городов, клавиатуры, `aria-pressed`, `aria-live`, отсутствия ошибок и горизонтального переполнения.
